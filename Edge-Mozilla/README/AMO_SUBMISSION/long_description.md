No YouTube Shorts - GUI

Description

No YouTube Shorts - GUI empêche l'apparition du panneau "Shorts" sur YouTube et restaure l'interface vidéo classique. L'extension cible uniquement les éléments d'interface liés aux « Shorts » (pas le contenu des vidéos) et n'envoie aucune donnée externe.

Fonctionnalités

- Supprime/masque la section Shorts dans les pages YouTube.
- Empêche le comportement d'enchaînement automatique des Shorts dans l'interface.
- Interface compacte via popup pour activer/désactiver rapidement le blocage.

Respect de la vie privée

- Aucune donnée utilisateur n'est envoyée ou collectée.
- Utilise uniquement le `content script` pour modifier l'interface locale du site.

Permissions requises

- `storage` : pour mémoriser le choix utilisateur (activer/désactiver).

Instructions d'installation

1. Téléverse l'archive signée (.xpi) via le Developer Hub d'addons.mozilla.org ou utilise le glisser‑déposer si tu disposes d'une version signée.
2. Pour les tests locaux : charge temporairement via `about:debugging` → Load Temporary Add-on → sélectionne `manifest.json`.
