Checklist de soumission AMO

- [ ] Compte développeur AMO créé et connecté.
- [ ] Fichier `.xpi` prêt (utiliser `ZIPS\NO-YOUTUBE-SHORTS-GUI-AMO-PACK.zip` ou `NO-YOUTUBE-SHORTS-GUI-FIREFOX.xpi`).
- [ ] Short description (copier `short_description.txt`).
- [ ] Long description (copier `long_description.md`).
- [ ] Release notes (copier `release_notes.md`).
- [ ] Screenshots à uploader : `AMO_screens/popup_1.png`, `AMO_screens/popup_2.png`.
- [ ] Icône 128x128 incluse dans l'archive.
- [ ] Politique de confidentialité (si nécessaire) ou texte ‘No data collected’.
- [ ] Choisir "unlisted" si tu veux distribution privée.

Étapes de soumission rapide :

1. Connecte‑toi à https://addons.mozilla.org -> Developer Hub.
2. Click "Submit a New Add‑on" -> Upload XPI.
3. Remplis les champs (short/long/release notes, category, tags).
4. Upload screenshots et icône.
5. Submit -> attendre la signature. Une fois signée, télécharge la XPI signée.

Si AMO renvoie des erreurs, colle ici le rapport et je corrige les fichiers.
