# No YouTube Shorts — GUI

Bloque l'interface « Shorts » de YouTube et restaure l'affichage classique des vidéos.

## Installation

- Depuis AMO : installe la version signée depuis la page du module.
- Développeur (local) : ouvrir `about:debugging` → This Firefox → Load Temporary Add-on → sélectionner `manifest.json` (ou l’XPI).

## Utilisation

Clique sur l’icône de l’extension dans la barre d’outils pour activer / désactiver le blocage des Shorts.
